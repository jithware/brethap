Brethap — це ще один додаток для медитації. Окрім таймера для медитації, він також дозволяє налаштовувати паттерни дихання для практики. Ваші сесії зберігатимуться, що дозволить відстежувати та переглядати статистику вашого прогресу у вигляді списку або календаря. Тривалість, параметри дихання та інші опції можна налаштувати за допомогою збережених пресетів. Готові пресети дихальних технік включають «4-7-8», «квадрат», «фізіологічне зітхання» та інші.

Для користувачів Wear OS також доступна спрощена версія.

Повна документація для смартфонів: https://github.com/jithware/brethap

Повна документація для Wear OS: https://github.com/jithware/brethap_wear
